📤 BU ส่งข้อมูลเพื่อเข้ารับการตรวจ (Pack)

ขั้น ① ของวงจร: BU กรอกข้อมูลที่ GAT แจ้งว่าจะตรวจ + แนบลิงก์หลักฐาน → ระบบรันเลข PACK-xxxx ลงชีตกลางทันที — GAT เลือกลงตรวจในแท็บ "🤖 AI Review" ต่อ — SLA: ส่งข้อมูลให้ครบภายใน 3 วันทำการนับจากได้รับแจ้ง (WI-01)

สถานะการส่งทั้งหมด (จากชีตจริง)
เลข PackBUขอบเขตหัวเรื่องลิงก์สถานะส่งเมื่อ
ยังไม่มีข้อมูล — กด รีเฟรชสถานะ

การเชื่อมกับ Google Sheet BCT สถาปัตยกรรม 2 ฐาน

ทีม BU บันทึกรายการตรวจสอบบนชีท BCT (ชีท GAT_Registers, GAT_Entries, GAT_Issues — รันเลข GAT-REC-xxxx ฝั่งเซิร์ฟเวอร์) → แพลตฟอร์มนี้ดึงขึ้นกลางผ่าน Google Apps Script Web App

  1. เปิด Google Sheet BCT → เมนู ส่วนขยาย (Extensions) → Apps Script
  2. วางโค้ดจากไฟล์ gas-bct-bridge.js ทั้งไฟล์ → บันทึก
  3. เลือกฟังก์ชัน setupSheets → กด Run ครั้งเดียว (อนุญาตสิทธิ์) — สร้างชีทครบ + AuditLog อัตโนมัติ
  4. Deploy → New deployment → Web app · Execute as: Me · Access: Anyone → คัดลอก URL ลงช่องด้านล่าง → บันทึก API URL
  5. กด 📥 Import จาก BCT — ข้อมูล live จะผสมกับ seed แล้วขึ้น Dashboard ทันที
ส่งออก = Export CSV คอลัมน์ตรง GAT_Registers (วางลงชีทได้เลย) · ทุกการเขียนของ GAS ประทับเวลาลง GAT_AuditLog อัตโนมัติ

🧾 ทะเบียนข้อเสนอแนะทั้งหมด

แท็บนี้ = ทะเบียนกลาง (อ่านอย่างเดียว) · ออกใบ: แท็บ P-04 ตรวจ+ออกใบ · BU ตอบ: แท็บ P-05 BU ตอบใบ · GAT ปิด: แท็บ P-06 ปิดประเด็น · BU คัดค้านประเด็น: อุทธรณ์ OAC ภายใน 7 วัน (P-07 กฎบัตรข้อ 9)

เลขที่ระดับหัวข้ออ้างชีท+แถวสถานะการตัดสิน BUหลักฐาน/เหตุผล · ผู้รับผิดชอบ
🗂 ขั้น 2 — ทีม GAT เลือกหัวข้อที่ BU ส่งข้อมูลมาให้

ดูสถานะการส่งจากชีตจริง → เลือก หัวข้อ/Pack ที่จะลงตรวจ — เลือกแล้วส่งต่อขั้น 3 (ตรวจด้วย AI)

เลือกเลข PackBUขอบเขตหัวเรื่องสถานะ
ยังไม่มีข้อมูล — กด รีเฟรชสถานะ
🔍 ขั้น 3 — ทีม GAT เข้าไปตรวจ โดยใช้ AI ตรวจข้อมูลที่ BU ส่ง

เลือก Pack → กดสร้างชุดคำสั่ง AI (ระบบกรอกหัวข้อ/กติกา GAT ให้ครบ) → คัดลอกไปวางในโปรแกรม AI ที่ใช้ตรวจ

เมื่อ AI ตรวจเสร็จ → วางผลใน ขั้น 4 AI ออกข้อเสนอแนะ ต่อทันที
💡 ขั้น 4 — AI ออกข้อเสนอแนะจากการตรวจ

GAT วางผลที่ AI ตรวจได้ (ข้อความเดียวขึ้นบรรทัดใหม่ = 1 ใบประเด็น) → กดตัดเป็นใบ = ได้รายชื่อ "ข้อเสนอแนะจาก AI" รอคัดเลือก

✂️ ขั้น 5 — ทีม GAT คัดเลือกข้อเสนอแนะจาก AI

ติ๊ก ✅ เฉพาะใบที่จะใช้จริง (ตัดใบซ้ำ/ใบตั้งข้อสังเกตไม่ได้ตาม WI-02) — กรอกชื่อผู้คัดเลือก แล้วกดขั้น 6 ต่อ

🧾 ขั้น 6 — ทีม GAT ส่งข้อเสนอแนะที่คัดเลือกแล้วให้ BU

กด ออกใบ REC = รันเลข GAT-REC → ชีตกลาง + สถานะเปลี่ยน "ส่งให้ BU แล้ว" — BU เห็นใบที่แท็บ 8 ต่อ

✍️ ออกใบ REC มือ (GAT ใบที่ไม่ผ่าน AI / ออกตรง ๆ)

เลือกต้นเรื่องจาก Registers → ระดับ → ผู้ออก/REF_PM_WI/ผู้อนุมัติ → กด รันเลข (ส่งเข้า BCT อัตโนมัติ)

📨 ติดตาม: ใบที่ส่งให้ BU แล้ว (รอ BU ตอบ)

ใบจากชีตจริงที่สถานะ "ส่งให้ BU" — ติดตามให้ครบตาม SLA 5 วันทำการ

เลขใบหัวข้อระดับสถานะ
— ยังไม่มีใบที่ส่งแล้วในขอบเขตโชว์ —
🛠 ขั้น 7 — ทีม BU นำข้อเสนอแนะไปแก้ไข

ดาวน์โหลดรายการใบที่ BU ต้องทำ ครบชุด (อ่านง่าย พาไปแก้ได้ทันที) — เมื่อแก้แล้ว → บันทึกคำตอบที่ แท็บ 8

เลขใบหัวข้อระดับต้องส่ง (ตาม SLA 5 วันทำการ)
— ยังไม่มีใบให้ทำ —

✍️ BU ตอบใบ (แก้ไข / ไม่แก้ไข) — ขั้น P-05

BU กรอกบนชีท BCT ตรงคอลัมน์ BU_DECISION / EVIDENCE_URL / NO_FIX_REASON / RESPONSIBLE หรือกรอกผ่านฟอร์มนี้ — ระบบส่งค่าทันที

🔒 GAT ตรวจคำตอบ → ปิดประเด็น (ขั้น ⑨ — P-06)

หลัง BU ส่งคำตอบ (แก้+หลักฐาน / ไม่แก้+เหตุผล): GAT เลือกใบ → กดปิด — ระบบจด AuditLog "close_issue" — สถานะเปลี่ยนเป็น ปิดแล้ว (GAT ยืนยัน) — ไม่สามารถปิดใบที่ BU ยังไม่ตอบ · ป้าย 🔴 ที่ BU ไม่แก้ และขัดกฎหมายจริง GAT ต้องยืนยันกลับอย่างเป็นทางการ (SOP ขั้น ⑤)
